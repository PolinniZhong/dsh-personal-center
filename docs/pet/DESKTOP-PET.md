# 桌面宠物(Desktop Pet)—— 方向方案(已落地 v0.4.x)

> 目标:在 DSH「个人」里加一个**桌面宠物**:一个会动的、由真实用量数据驱动情绪的浮游小家伙。
> 状态:**v0.4.x 已实现**(双皮肤:小黑鲸 V2 / 小蓝鲸,数据驱动 5 情绪,当前 v0.4.22)。本文保留原始方案 + 落地决策记录。

## 1. 定位

- 不是"真正的系统桌面宠物",而是 **DSH Web 界面里的浮游宠物**:在应用右下角悬浮、可拖动、可点击;
- **入口:「个人」外层 tab(与「个性化」平级)** —— `个人资料 | 个性化 | 宠物`;宠物本体渲染在整个应用(不是只在设置面板里);
- 核心卖点:**与真实数据联动** —— 用统计(今日 Token、工具调用、缓存命中率、成本)驱动宠物的情绪与动作。

## 2. 行为设计(数据驱动)— 已实现

| 情绪/状态 | 触发条件(校准后阈值) | 表现 |
|---|---|---|
| 🟢 开心 | 缓存命中率 ≥ 70%(兜底基线) | 平时静态待机;情绪变化/逗弄时蹦跳 |
| 🔴 忙碌 | 今日工具调用 ≥ 400 次 | 平时静态待机;情绪变化/逗弄时挥鳍/点头 |
| 🟡 疲惫 | 今日 Token ≥ 2 亿 | 平时静态待机;情绪变化/逗弄时喘气 |
| 💸 钱包痛 | 今日成本 ≥ ¥10(需配置价格) | 平时静态待机;情绪变化/逗弄时捂胸口颤抖 |
| 💤 打盹 | 无活动 ≥ 10 分钟 | 平时静态待机;情绪变化/逗弄时惊醒/呼吸 |
| 点击交互 | 点击宠物 | 气泡说出随机事实(今日 Token、命中率、Top 工具、今日成本)+ 播一次动作 |

> **行为规范(参考 Codex 宠物设计,2026-08-20 重设计)**:宠物**常驻显示,平时静止待机**(单帧静态表情,无任何循环动画),不打扰工作;**情绪变化时播放一次对应动画**(~2 秒)后回到静止;鼠标**悬停或点击**也会按当前情绪播放一次动作动画。Codex 官方宠物格式([pet.json/spritesheet 规范](https://codexpet.xyz/zh/spec/))同样区分 idle 待机行与 waving/jumping 等事件动作行。
> 优先级:钱包痛 > 疲惫 > 忙碌 > 打盹 > 开心。**打盹先于开心判定**(原组件 bug:高缓存用户永不入睡)。
> 数据全部来自 `/personal-center/stats`(今日 Token/工具调用、成本 `cost.today`、总缓存命中率、最近活动时间),30 秒轮询。

## 3. 形态与素材(落地决策)

- **皮肤:双皮肤(v0.4.5)** —— **「圆滚滚小黑鲸」(v0.4.16 升级 V2:正面偏 30°、去投影、细节更丰富)** + **「圆滚滚小蓝鲸」**(DeepSeek 蓝色品牌,正视偏左 30 度);配置 `skin` 字段(`black-whale` / `blue-whale`)切换,即时生效;
- **素材格式:动画 WebP(决策点 2 结论)** —— 由各皮肤素材库 `assets/animations/frames/*_processed.png`(RGBA,带抗锯齿半透明像素)合成,真 alpha 透明、每皮肤 ~400-470KB(比 GIF 小一半);
  - GIF 只支持二值透明,深色主题下白边明显(已实测:半透明像素=0,角点为近白透明);
  - 转换脚本:`AI桌面宠物/black-whale-petblack-whale-pet-圆滚滚小黑鲸 V1/scripts/gif2webp.py <pet-repo> <plugin-repo> <skin>`(本机 PIL 一次性转换,产物入库);
- **集成方式:宿主托管素材(决策点 3 结论)** —— 素材按 `lib/pet-assets/<skin>/{animations,idle}/` 组织,宿主 `/personal-center/pet/assets/*` 静态路由(皮肤+子目录+文件名三重白名单 + immutable 缓存),客户端按需懒加载、只播放当前情绪的动画(省 CPU);不把 base64 塞进 client bundle;
- 动画节奏与 GIF 一致:happy 120ms / busy 90ms / exhausted 200ms / money-pain 180ms / dozing 250ms(每情绪 6 帧)。
- **V2 迭代经验(2026-08-22)**:
  - **素材版本参数 `?v=N`**:素材路径不变、内容更换时,宿主 `immutable` 缓存会让浏览器沿用旧素材——素材 URL 统一带 `?v=` 版本号,升级素材时递增(当前 v4),强制重新拉取;
  - **角色尺寸统一要保留位移**:不同皮肤帧内角色占比不同(黑鲸 V2 60%×56% vs 蓝鲸 89%×78%),`gif2webp.py --ratio 0.78` 按 bbox 中心为锚统一尺寸(不强制居中),否则蹦跳等整体位移动画被抹平;
  - **GIF 残影**:合成 GIF 时帧 2+ 是局部差帧且 `disposal=None` 会叠残影——重存为「每帧全图 + disposal=2」可消除(README 情绪 GIF 已按此修复)。

## 4. 技术实现

- **渲染位置**:客户端 bundle 在 `document.body` 挂 `position:fixed` 浮层(右下角),`z-index:2147483000`(低于模态);不依赖设置面板;
- **组件**:原 pet-widget ES Module 内联进 `lib/client.js` factory 作用域(纯 DOM/CSS,零依赖,不使用 react-dom);
- **数据**:复用 `/personal-center/stats`(60s 宿主缓存);轮询 30s;接口失败保留上一状态;
- **配置持久化**:自有命名空间 `personal-center-pet`(`{enabled, size, position, posOverride, opacity}`),环回路由 GET/POST `/personal-center/pet`(决策点 1:今日成本桶加在宿主 `computeStats`,产出 `cost.today`);
- **拖拽**:pointer 事件记录偏移,松手把 `{left, top}` 存回配置(刷新恢复);窗口缩放钳制在视口内;
- **性能**:transform/opacity 动画不触发重排;仅当前情绪的 WebP 在播放;`prefers-reduced-motion` 关闭动画。

## 6.5 宠物状态概览(v0.5.0 → v0.6.0)

- 悬停宠物右上角「会话状态」按钮(或点宠物)→ 毛玻璃浮层面板:会话状态(运行中 / 失败 / 已完成(就绪)/ 待机)+ 摘要(进行中·失败·完成)+ 会话列表;点面板外 / ESC 关闭,无关闭按钮;**面板打开时隐藏数据气泡,退出后恢复**;
- **动作级实时状态(v0.6)**:running 会话从最后一条 `tool-call` 节点提取动作文案——`read`/`write`/`edit` →「正在读取/写入/编辑 <文件末段>」、`bash` →「正在执行命令 …」、`web_search` →「正在搜索」;思考中无 tool-call 回落「运行中」;完成显示「就绪」绿徽标;
- **数据 = 平台已有投影**(`ctx.get("sessions")` 的 list + `manager.get(id)` 的 `getSnapshot().nodes`),零 host 改动、零端点、零轮询;面板打开才订阅、关闭即退订销毁(空闲零开销);实时性由 host `session/event` 帧驱动,零新增订阅;
- **失败如实**:会话最近一次 agent 交互失败(`lastAgentError`,host `agent/error` 驱动)即标红「失败」,绝不伪装绿;优先级 失败 > 运行中(带动作)> 已完成 > 待机;
- 情绪映射 失败→着急(exhausted)/ 运行中→busy / 完成→happy / 空闲→dozing;
- 交互规格与 M0 验证结论见 `docs/pet/宠物状态概览-设计规格与交接.md`;v0.6 迭代规格见 `状态卫士/宠物状态概览-动作级实时状态-设计规格.md`;冒烟测试 `/tmp/pet-client-smoke7.mjs`(30 项)。

## 6.6 新动作与会话情绪驱动(v0.8.0)

- **5 个新动作素材**(黑鲸 + 蓝鲸,素材版本 `?v=v5`):
  - 情绪态:thinking(思考中)/ waiting(等你回复)/ celebrate(完成庆祝);
  - 交互触发:drag(拖拽小碎步)/ wave(点击打招呼);
- **会话状态情绪实时驱动(常驻,不依赖面板)**:
  - 宠物启用即订阅 `sessions.list`,thinking/waiting/celebrate 实时生效;
  - 优先级:失败 exhausted > 等你回复 waiting > 思考中 thinking > 忙碌 busy;
  - **情绪锁仲裁**:会话有活动时锁定(会话实时状态优先),stats 用量轮询不覆盖;会话空闲解锁并立即恢复 stats 情绪;
  - **完成庆祝**:running 下降沿(运行→停止且无失败)触发 celebrate(completed 标志对当前选中会话不置位,故不依赖它);
  - **持续情绪**:thinking/waiting 播完动画保持对应待机帧,不被拉回睡觉。

## 7. 已知限制与下一步

- **全屏移动不可行**:桌面端是 Tauri 宿主 + iframe,插件无法出 DSH 窗口(架构证据见 PLATFORM-NOTES §11);要全屏需 DSH 官方浮层能力或独立小应用;
- 帧间一致性:happy 帧 5(侧面)、exhausted 帧 5(倾斜)有轻微漂移,需重新生成(素材侧,需生图工具);
- 悬停即触发动作:若鼠标经常划过宠物会频繁播动作(后续可改为"点击才动"或加开关);
- 阈值内置不可调(后续可加设置项);
- USD 币种配置下「钱包痛」阈值(¥10)语义不匹配(本机为 CNY);
- 三平台(Windows/Linux)未实机验证,理论 Chromium 均支持动画 WebP;
- 素材质量(角色精致度)用户反馈待优化,属素材侧迭代;
- 状态概览显示的是"当前活跃会话"(list 投影),历史完成会话不在列表(平台 list 仅含活跃/最近会话,与「会话回顾」口径不同)。
