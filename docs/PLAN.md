> 目标:把设置里的「个性化」改造成像 Codex / ChatGPT 桌面端那样的**个人中心**——
> 设置导航新增「个人」分区,内含 **个人资料 / 个性化 / 语音** 三个 tab。

## 1. 目标形态

设置面板导航区(常规 / 模型 / 插件 / 插件市场 / …)中:

- 现有「个性化」导航项**改名「个人」**;
- 点击「个人」,内容区显示 tab 栏(交互参考「插件」分区内的 tab:插件列表 /
  插件控制台 / 技能):

| Tab | 内容 | 状态 |
|---|---|---|
| 个人资料 | 累计 Token 消耗、今日/近 7 天用量、**按模型/提供方分布**、最长聊天时长、常用工具/插件、会话数 | 本期实现 |
| 个性化 | 现有「自定义指令」多行文本框(原样迁入) | 本期迁入 |
| 语音 | Omi 语音配置(停靠位) | 预留,后续 |

## 2. 技术方案

### 2.1 结构(纯前端改造)

- 仍是一个 `settings.section` 条目(id `personal-center`,label「个人」,order 30);
- 该分区的内容组件**内置 tab 栏**(React state 切换,复用 DSH 设计令牌);
- 「个性化」tab 直接复用现有 `CustomInstructionsSection`(命名空间
  `custom-instructions` 不变 → 已存数据无缝延续);
- **预留扩展点**:仿「插件」分区的 `settings.plugins.tab` 槽位(plugin-console
  正是这样停靠的),本分区声明 `personal-center.tab` 槽,未来 Omi 等插件可
  停靠「语音」tab,而无需改本插件代码。

### 2.2 统计服务(宿主端,本期核心)

- 新增宿主服务 + RPC(走现有 api-gateway / `connection.api` 通道):
  `personal-center/stats?range=today|7d|all`;
- 实现:扫描会话日志目录 → 聚合 → **进程内缓存**(按天快照 / 新事件触发
  增量刷新),避免每次打开面板全量重扫;
- 隐私边界:只聚合数字,不读取对话正文内容。

## 3. 统计字段与数据源(全部已确认存在于本机)

| 字段 | 数据源 | 算法 |
|---|---|---|
| 累计 Token 消耗 | 会话日志 request header 的 usage(输入/输出/缓存) | 全量求和;可按 今日/7天/全部 切分,按模型分列 |
| 按模型 / 提供方分布 | 请求路由的 provider + model | 按 provider+model 分组求和 Token/请求数;可选「估算成本」列(每百万 token 单价由用户配置,不硬编码价格) |
| 今日 / 近 7 天用量 | 同上 + 请求时间戳 | 按天归组,渲染柱状图 |
| 会话数与总轮次 | 会话目录 + turn 事件 | count |
| 最长聊天时长 | 会话首条消息 ↔ 末条消息时间戳 | max(跨度),展示时长 + 会话标题 |
| 常用工具 / 插件 | tool start/settle 事件 | 按工具名计数 Top N;MCP 按 `mcp__<server>__<tool>` 归组展示服务器分布 |

存储位置:`<DSH_HOME>/data/dsh/sessions/**/session.jsonl.zstd`
读取能力:`@deepseek-ai/dsh-session-persistence-jsonl`(应用同款,zstd 解压)。

### 2.3 浏览器端渲染

- 「个人资料」tab:今日卡片(累计 Token / 轮次 / 工具调用)+ 近 7 天柱状图
  (**纯 SVG 自绘**,不引入图表依赖,保持客户端 bundle 轻量)+ 工具 Top 列表 +
  MCP 服务器分布 + 最长聊天时长卡片;
- 加载态 / 空态(无历史数据时给出引导文案)。
