## 0. 一句话定位(多长度)

- **超短(8 字)**:DSH 的「个人中心」。
- **短(1 句)**:给 DeepSeek Harness 加一个本地「个人中心」——Token/工具用量统计 + 全局自定义指令 + 由真实数据驱动情绪的黑鲸宠物。
- **中(2 句)**:`dsh-personal-center` 是 DeepSeek Harness 的设置插件,在设置里新增「个人」分区:一边是 GitHub 贡献图风格的使用统计(今日/累计 Token、按模型分布、常用工具)、按模型成本估算与全局自定义指令,一边是一只由真实用量驱动情绪的**圆滚滚小黑鲸**(默认安静、逗它才动)。纯本地运行,不联网、不读聊天正文。

## 1. 这是什么

- **项目名**:`dsh-personal-center`(中文名「DSH 个人中心」)
- **类型**:DeepSeek Harness(DSH)桌面端/Web 端的本地插件
- **一句话解决的问题**:让 DSH 用户像看 GitHub 贡献图、像用 Codex 的自定义指令一样,**量化自己的 AI 使用、并让 AI 更懂自己**。

## 2. 背景与痛点(文章可引用的"为什么做")

1. **官方空白**:DSH 官方桌面端目前没有"个人中心/全局使用统计",也没有 ChatGPT/Codex 桌面端那样的「个性化 → 自定义指令」;
2. **量化反馈心理**:用户喜欢看"今天用了多少 Token/工具",类似 GitHub 贡献图、WakaTime、Duolingo 打卡——这是极客天然的诉求;
3. **多模型成本对比**:很多人同时用 DeepSeek、Claude、GPT 等多个模型,想知道每个模型各自烧了多少 Token(≈成本),但登录各家后台对比很麻烦;
4. **想让 AI 更懂自己**:用户想把身份/工作原则/回答偏好固化下来,对所有聊天生效,而不是每次重复说明。

## 3. 目标用户画像

- DSH 桌面端/Web 端的日常用户;
- **重度 AI 用户**(每天大量对话、多会话);
- **多模型用户**(DeepSeek + 其他,想对比消耗);
- **开发者/极客**(喜欢 GitHub 贡献图式的量化反馈);
- 产品/设计等**非程序员但高频用 AI 写代码/做内容**的人。

## 4. 核心功能(每个都要写"是什么 + 用户价值")

### 个人资料(统计)——用量一目了然
| 功能 | 是什么 | 用户价值 |
|---|---|---|
| 今日概览 | 今日 Token 消耗 / 会话数 / 工具调用 | 一眼看到"今天用了多少" |
| 累计数据 | 累计 Token / 最长聊天时长 / 会话总数 | 长期使用全景 |
| Token 活动 | GitHub 贡献图风格热力图,支持 每日/每周/累计 三态 | 极客感、活动轨迹可视化 |
| 按模型分布 | 按 provider+model 拆分 Token 与请求数 | **多模型消耗/成本对比** |
| 常用工具 | 按调用次数排序(含 MCP 工具) | 了解自己的 AI 工作流 |

### 模型成本(估算)——多模型烧钱一目了然
- 按模型 × 每百万 token 单价估算成本,**分币种**(¥/$)分别合计;
- 支持**峰谷分时**(DeepSeek 官方口径:北京 9-12 / 14-18 高峰),内置官方预设价,可自改;
- 展示本周 / 本月 / 累计成本,外加**缓存命中率**(省钱洞察)。

### 个性化(全局自定义指令)——让 AI 更懂你
- 等价于 ChatGPT / Codex 桌面端的「个性化 → 自定义指令」;
- 输入身份/工作原则/回答偏好,保存后**本机所有会话(含已存在的)下一次请求立即生效**;
- 支持清空;清空后从系统提示词消失、不占 token。

### 桌面宠物(黑鲸)——让数据"活"起来
- 界面右下角一只圆滚滚小黑鲸,**常驻显示,平时静止不打扰,情绪变化时会播放对应动画**,鼠标悬停/点击也会按当前情绪做个小动作(参考 Codex 宠物设计);
- **5 种数据驱动情绪**(开心/忙碌/疲惫/钱包痛/打盹),由今日 Token、工具调用、缓存命中率、今日成本驱动,30 秒轮询;
- 点击吐随机数据气泡(今日 Token / 缓存命中率 / 最常用工具 / 今日成本);
- 可拖拽到任意位置并记忆、右键隐藏、透明度三档、一键开关。

## 5. 差异化卖点(推荐理由)

1. **补官方空白**:官方没有个人中心/全局统计;
2. **纯本地 + 隐私**:只聚合数字、**不读聊天正文**;接口仅回环 127.0.0.1,不联网、无遥测;
3. **原生一致的体验**:版式/配色/交互对齐 DSH 原生「插件」分区,深浅色自适应、中英双语;
4. **极客感**:GitHub 贡献图式的 Token 活动热力图;
5. **成本透明**:按模型对比,直面"今天烧了多少、哪个模型更划算"。
