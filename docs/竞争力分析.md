## 1. 产品组合（我们是谁）

```
DSH 个人中心
├── ① 个人资料统计：跨会话聚合（今日/累计 Token、会话数、工具调用、活动热力图、按模型分布、常用工具、会话回顾）
├── ② 模型成本估算：峰谷分时 / 分币种 / 官方预设价 / 缓存命中率
├── ③ 个性化自定义指令：全局注入
├── ④ 桌面宠物：5 种数据驱动情绪（开心/忙碌/疲惫/钱包痛/打盹）
└── ⑤ 宠物状态概览（v0.5 新增）：对话状态机——几个在跑/几个失败，失败如实，毛玻璃浮层
```

**一句话**：别人做"单点功能插件"，我们做"**用户每天都会打开看一眼的个人工作台**"。

## 2. 竞品地图

| 维度 | 竞品现状 | 我们的位置 |
|---|---|---|
| 用量统计 | 红海 101+ 个（余额/热力图/成本翻版，多数 0-10★"做了但糙"） | 打包形态 + 设计质量碾压单点翻版 |

## 3. 六维竞争力评估

| 维度 | 评分 | 依据 |
|---|---|---|
| 组合独特性 | ★★★★★ | 市场上无"统计+成本+个性化+宠物+状态概览"组合；单点竞品多，组合唯一 |
| 设计/交互质量 | ★★★★★ | 交互设计师+PM 驱动、DSH 令牌、毛玻璃、轻量约束——碾压"做了但糙" |
| 状态概览差异化 | ★★★★☆ | "失败就是失败 + 宠物拟人化"= 情感化状态设计；竞品是监控面板 |
| 技术轻量 | ★★★★☆ | 新增模块复用投影/事件驱动/懒挂载，近零开销 |
| 家族生态 | ★★★★☆ | 个人中心为锚点（+会话库 dsh-session-kb），统一品牌对抗碎片化 |
| 风险敞口 | ★★★☆☆ | 内核追平风险持续（已追平统计条/搜索两次），靠组合维持差异 |

## 4. 核心结论与护城河

**竞争力 = 「个人工作台」生态位，不是单一功能。**

护城河：
1. **组合完整性**——复制单功能易，复制"数据+个性化+陪伴+状态"一体化体验难；
2. **设计质量**——交互设计驱动是团队基因；
3. **家族生态**——个人中心是锚点，新能力长在它身上（宠物状态概览即例）；
4. **轻量技术**——"装了不拖慢电脑"是用户可感知的信任。

**最大威胁**：内核追平。应对：定位在"跨会话聚合 + 成本 + 个性化 + 陪伴"产品层——官方修底层 bug/加基础 UI，不影响我们的产品层价值。
