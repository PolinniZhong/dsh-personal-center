## 1. 一句话定位

在 v0.7「分层指令」(全局 → 工作区)之上,再加一层**条件指令**(按模型/时段等运行时条件自动切换),并让**模板可导入导出**(沉淀与分享)。对标 Cursor Rules 的 glob 条件触发 + 行业模板分享惯例。

## 2. 背景与价值

- v0.7 已解决"不同工作区不同人设"的**空间**维度;但同一工作区内还缺**条件**维度:
  例如"用 deepseek-v4-flash 时给精炼指令、用 pro 时给深度推理指令";"工作时间要正式语气、深夜要简洁"。
- 模板库目前是"个人私有 + 本地手动存",无法**导出分享 / 备份迁移**。

| 价值 | 说明 |
|---|---|
| 条件适配 | 同一工作区按模型/时段自动换人设,零手动切换 |
| 复用沉淀 | 模板导出 JSON,新机器/他人一键导入 |
| 生态差异化 | Cursor 有 glob 条件(Cursor Rules),但"模型/时段条件 + 模板分享"是组合空白 |

## 3. 候选清单(细化 + 优先级)

### 方向 A:条件注入

| 编号 | 候选 | 触发信号 | 可行性 | 优先级 |
|---|---|---|---|---|
| A1 | **按模型条件** | `context.agent.options.{provider,model}`(官方 `{{provider}}/{{model}}` 同源,已确认) | ✅ 可行 | **P0** |
| A2 | **按时段条件** | 注入时本地时间(北京时间) | ✅ 可行 | **P0** |
| A3 | **按任务条件** | 任务类型/工具调用 | ⚠️ assemble context 无任务信号 | ❌ **不列入**(无开放权限) |
| A4 | **按文件条件** | 当前文件 / glob(对标 Cursor Rules) | ⚠️ assemble context 无"当前文件"信号 | ❌ **不列入**(不可行) |

> 说明:A1/A2 直接可用(信号已确认);A3/A4 在注入时点拿不到可靠信号,当前**不列入 v0.8**,
> 待内核开放文件/任务信号后重新评估。

**条件模型建议**(A1/A2):
- 数据结构:`personal-center-instructions.rules = [{ id, when: {model?/provider?/timeRange?}, text }]`;
- 优先级:**条件 > 工作区 > 全局**(条件命中则追加在全局+工作区之后,最具体优先);
- 与 v0.7 一致走 `system-prompt/assemble` 事件,命中即追加 text,无命中不追加(向后兼容)。

### 方向 B:模板导入导出

| 编号 | 候选 | 说明 | 优先级 |
|---|---|---|---|
| B1 | **导出模板** | 单个/全部模板 → JSON(复制到剪贴板 / 下载文件) | **P0** |
| B2 | **导入模板** | 粘贴/选择 JSON → 校验字段 → **去重(id/名称)+ 覆盖策略**(询问/跳过/覆盖) | **P0** |
| B3 | 分享模板 | 一键复制模板为可读文本/短链接 | P1(列入) |

## 4. 对抗式审查

| 攻击 | 结论/对策 |
|---|---|
| 条件叠加混乱 | 预览(复用 v0.7「指令应用示例」)展示最终合并 + 条件命中来源;优先级明确(条件>工作区>全局) |
| 条件判断开销 | 注入时内存匹配,与 v0.7 同量级,无轮询 |
| 文件/任务条件不可行 | 诚实标注 A3/A4 为"待内核信号",本期不做或降级;不假装实现 |
| 导入脏数据 | 严格校验(id/name/desc/text 字段 + text 必填),坏 JSON/坏字段丢弃并提示 |
| 导入覆盖冲突 | 明确策略:同名/同 id → 提示"跳过 / 覆盖",默认跳过(不静默覆盖用户数据) |
| 与工作区关系 | 条件是工作区内的**进一步细分**,不是新层级;条件层对无配置用户透明(不生效) |

## 5. 技术可行性(源码级确认)

- ✅ 条件信号:`assembleContextFor(agent, signal)` 返回 `{agent, scope, signal}`;`context.agent.options.{provider,model}` 与官方 `{{provider}}/{{model}}` 同源(dsh-agent-loop:1024-1025);`cwd` 同 v0.7;本地时间无依赖。
- ✅ 注入通道:v0.7 已验证的 `system-prompt/assemble` 事件,条件命中在事件里追加 section 文本即可。
- ⚠️ A3/A4:assemble context 无任务/文件信号,需内核提供或降级。
- ✅ 导入导出:纯客户端 JSON 序列化/反序列化 + 现有 `/personal-center/instructions` 读写,零新依赖。

## 6. 确定范围(v0.8)

**做**:A1(按模型)+ A2(按时段)+ B1(导出 JSON)+ B2(导入 JSON)+ B3(分享)。
**不做**:A3(任务)/ A4(文件)——无开放权限/不可行,待内核开放信号后重新评估。
