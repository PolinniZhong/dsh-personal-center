# 桌面宠物(Desktop Pet)—— 方向方案

> 目标:在 DSH「个人」里加一个**桌面宠物**:一个会动的、由真实用量数据驱动情绪的浮游小家伙。

## 1. 定位

- 不是"真正的系统桌面宠物",而是 **DSH Web 界面里的浮游宠物**:在应用右下角悬浮、可拖动、可点击;
- **入口:「个人」外层 tab(与「个性化」平级)** —— `个人资料 | 个性化 | 宠物`,不放进个人资料的二级子 tab(层级太深);宠物本体渲染在整个应用(不是只在设置面板里);
- 核心卖点:**与真实数据联动** —— 用我们的统计(今日 Token、工具调用、缓存命中率、成本)驱动宠物的情绪与动作,而不是一个死板的贴纸。

## 2. 行为设计(数据驱动)

| 情绪/状态 | 触发条件 | 表现 |
|---|---|---|
| 正常 | 默认 | 眨眼、轻微浮动 |
| 忙碌 | 今日工具调用多 / 会话活跃 | 快速动、冒汗/转圈 |
| 疲惫 | 今日 Token 很高 / 最长会话很长 | 打哈欠、趴下 |
| 钱包痛 | 今日/本月成本高 | 捂钱包、皱眉 |
| 开心 | 缓存命中率高(省钱) | 蹦跳、冒星星 |
| 打盹 | 最近几天无活动(Token 活动冷) | 睡觉 zZ |
| 点击交互 | 点击宠物 | 气泡说出随机事实(今日 Token、命中率、常用工具 Top1、本周成本…) |

> 情绪所需数据全部来自现有 `/personal-center/stats`,无需新数据源。

## 3. 形态与皮肤

- **首个皮肤已定:「小黑鲸」**(DeepSeek 的黑色小鲸鱼,用户手绘);
- 后续可增加**多套预设表情**(同一只鲸鱼的不同表情:开心/忙碌/疲惫/打盹/钱包痛等);
- 宠物本体:**纯前端矢量/CSS 自绘**(可动画的小鲸鱼),零外部资源;
- 皮肤/表情以**预设列表**形式维护,便于扩展。

## 4. 技术可行性

- **渲染位置**:客户端 bundle 运行在整个应用中,可以在 `document.body` 挂一个 `position:fixed` 的浮层(右下角),**不依赖 settings 面板**;
- **动画**:宠物本体用 **CSS 动画 + 少量 JS 定时循环**即可(眨眼/浮动/蹦跳),不必引入 react-dom 独立根或任何库(保持零依赖);
- **数据**:复用 `/personal-center/stats`(与个人资料同源,60s 缓存);
- **配置持久化**:沿用自有环回路由 + settings.yaml 命名空间(如 `personal-center-pet`:`{enabled, skin, x, y}`),绕开设置白名单;
- **拖拽**:pointer 事件记录偏移,存回配置。

## 5. 里程碑

| 阶段 | 内容 |
|---|---|
| P1 最小宠物 | 右下角浮游小动物(CSS 动画)+ 可拖拽 + 开/关(在「个人」加开关) |
| P2 数据驱动 | 接入 stats 驱动 3-5 种情绪/动作 + 点击气泡说事实 |
| P3 皮肤与成长 | 2-3 个皮肤;长期使用解锁皮肤(可选) |
